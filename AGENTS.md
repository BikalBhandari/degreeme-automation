# DegreeMe Automation

Spec-driven Playwright test suite for ASU Online's DegreeMe Quiz. Tests validate the quiz flow, AI-generated degree recommendations, and RFI submission across all degree types and interest areas.

## Agent skills

### Issue tracker

Issues and PRDs for this repo live as GitHub Issues (via the `gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

The canonical triage roles use the default label strings in this repo. See `docs/agents/triage-labels.md`.

### Domain docs

This repo uses a multi-context (monorepo) docs layout. See `docs/agents/domain.md`.

### Key skills

- **run-quiz-test** — walk through quiz selections and run a specific test path
- **repo-maintenance** — clean dead code, update agents/skills, validate build
- **grill-with-docs** — stress-test a feature plan against the domain model
- **to-prd / to-issues** — generate PRDs and break into vertical slice issues
